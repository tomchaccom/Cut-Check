# 트러블슈팅

문제가 생기면 **고치기 전에 여기부터 찾는다.** 같은 문제가 있으면 적힌 대로 해결한다.
없으면 직접 해결하고, **실제로 해결을 확인한 뒤에만** 아래 형식으로 추가한다.
추측이나 해결 못 한 문제는 적지 않는다 — 여기 적힌 건 전부 검증된 해결법이어야 한다.

## 형식

```markdown
### 한 줄 증상 (검색되는 말로: 에러 문구, 화면 이름, 명령어)

- 날짜 · 커밋: 2026-10-17 · abc1234
- 증상: 무엇을 했을 때 무엇이 보였나. 에러 문구는 그대로
- 원인: 왜 그랬나
- 해결: 무엇을 바꿨나 (파일:줄)
- 확인: 해결됐다는 걸 무엇으로 확인했나 (명령어, 테스트)
```
