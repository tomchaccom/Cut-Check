## 디자인과 다른 점 (고치지 않은 것)

- **로컬 모드 미션 화면 위에 미션 파일 줄이 남아 있다.** 디자인은 위치 표시 + 제목 + 단계 탭뿐. 로컬 모드엔 교실 폴더가 없어 미션을 바꿀 유일한 길이라 남겼다(아래 판단 6). 한 줄 가로 스크롤로 줄였다.
- **"파이썬 문법 물어보기" 위치** — 디자인은 설계 알약 줄 오른쪽. 지금은 떠 있는 버튼(폰 폭에서는 페이지 끝). 튜터 표시 규칙을 건드리지 않으려고 옮기지 않았다.
- 교실 안: 디자인의 "선생님이 올린 미션 N개." 문구와 "표시 없음 = 아직 안 열었어요" 범례가 없다.
- 04: 디자인의 "고른 자료로 실행 / 설계 고치기" 대신 기존 "실행 / 설계 수정" 문구를 그대로 둠.
- 강사 화면(로컬 모드): 교실 코드 자리·"질문 기록" 탭이 없고 탭은 "학생 · 미션 · 학생 추가"(계획대로). 제목은 "이 브라우저", 그 아래 목업 반 이름이 같이 보인다(기존 동작).
- 강사 홈: 표본 데이터에 오늘 기록 없는 학생이 없어 회색 폴더가 캡처에 안 나온다. 서버 모드에서 한 번도 로그인 안 한 학생은 폴더가 없다(명단을 합치지 않음).
- 말 걸 순간 줄에 이름이 두 번 나온다("민수 · 민수가 설계도를 냈어요."). `CC.alerts.say` 가 이미 이름을 담고 있어서.
- 학생 서랍에서 빨간 경고 상자(함정 보기 고름 / 약한 이유)가 빠졌다. 같은 정보는 "더 보기" 위험 패널과 "먼저 물어볼 것" 질문에 남아 있지만, `why.weak` 는 우선순위에 밀리면 서랍에서 안 보일 수 있다.
- 02 어두운 테마 "다음" 버튼·03 "자료로 확인하기" 는 아직 고르기 전(disabled) 상태라 흐리게 찍혔다 — 대비 수치는 재지 않았다.

## 계획에 없이 정한 것 (이유 · 틀렸을 때 비용)

1. `#moments` 는 감싸는 요소의 id, 목록은 기존 `<ol id="alert-list">` 그대로 — 기존 E2E(`#alert-list li`)와 새 E2E 둘 다 만족 — 비용: 마크업 한 줄.
2. 공통 `.pill`(버튼) 이름은 유지하고 강사 상태 칩을 `.hd .pill` 로 좁힘 — 공통 모양 한 벌 유지 — 비용: CSS 몇 줄.
3. "파이썬 문법 물어보기" 를 설계 줄 옆으로 옮기지 않음 — 튜터 표시 규칙과 배치를 같이 건드려야 함 — 비용: 디자인과 위치 차이 하나.
4. 기존 패널 **"지금 칭찬해주세요" 제목을 그대로 두고** "더 보기" 안으로 옮김 — 계획의 "그대로 옮긴다" 우선, 칭찬 금지는 "말 걸 순간" 영역에 적용 — 비용: 패널 제목 하나. **사람이 판단할 것** 에 올림.
5. 최종 수정 1회에 리뷰 지적 + 캡처에서 보인 깨짐(로고·미션 줄·튜터 버튼)을 같이 묶음 — 모두 몇 줄, 학생·교사가 바로 보는 것 — 비용: 수정 범위가 조금 넓어짐(재리뷰로 확인).
6. 로컬 모드 미션 파일 줄을 미션 화면에서도 남김 — 미션을 바꿀 유일한 길, E2E 도 이 길 — 비용: 디자인 차이 하나.
7. `js/core/missions.js` sm1 마지막 입력에 `counter: true` 추가 — CLAUDE.md "마지막 입력은 반드시 반례" 와 맞고, "새로 온 자료" 표시는 이 값이 있어야 뜸. 표시용으로만 읽힘(리뷰 확인) — 비용: 한 줄.
8. `sentence.css` 에 `[data-theme="dark"]` 블록이 없어 `styles.css` 처럼 세 블록으로 만듦, `--green-bg` 도 노랑 계열로 — 비용: 테마 토글 색만.
9. 파랑·초록·호박·산호 배경 위 `#fff` 글자를 `var(--paper)` 로(계획은 `--green` 예시만) — 어두운 테마에서 밝은 배경 위 흰 글자를 막음. 대비 수치는 리뷰가 양쪽 테마에서 확인 — 비용: 낮음.
10. `.page.wide`(1180px, sentence.html) — 02·03 두 단이 800px 에 안 들어감 — 비용: 클래스 하나.
11. 단계 탭을 미션 머리 아래로, 미션 고르기 전엔 머리째 숨김 — 빈 제목 노출 방지 — 비용: 마크업 몇 줄.
12. 02·03 왼쪽 단은 `#step1` 을 `data-side` 로 계속 보이게 함(복제 안 함) — 한 원본 — 비용: CSS 3줄.
13. 강사 홈 새 E2E 는 학생이 내기 **전에** 강사 화면을 연다 — `alerts.js` 는 화면을 열 때 이미 있던 제출은 알리지 않는다(기존 규칙). 계획 순서대로면 통과할 수 없었다 — 비용: "이미 있던 기록도 말 걸 순간에 보여야 한다" 가 의도였다면 기록에서 순간을 다시 만드는 순수 함수가 필요.
14. smoke 금지 단어 예외 `data-lint-ok` 를 계획 문구 "점수가 아니라 타이밍이에요" 한 줄에만 — 점수를 부정하는 문장 — 비용: 이 줄에 진짜 점수 문구를 넣어도 smoke 가 못 잡음.
15. 서랍의 시각·처음 선택·미션 알약은 fold 결과가 아니라 원래 이벤트에서 읽음(fold 에 그 값이 없다). 미션 한 개 범위의 접기는 `CC.fold.fold` 를 다시 불러 씀(규칙 복제 없음) — 비용: 예전 서버 기록에 `mid` 가 없으면 알약만 안 보임.
16. 폰 폭(≤600px)에서 튜터 버튼을 페이지 끝에 고정 배치 — 아래 여백으로는 스크롤 중 겹침이 안 없어짐 — 비용: 폰에서 버튼을 찾으려면 04 끝까지 내려야 함.
17. 로컬 미션 줄을 모든 폭에서 한 줄 가로 스크롤로 — 옛 규칙을 지워도 420px 에서 490px 높이 — 비용: 미션이 많으면 옆으로 넘겨야 보임.

## 남겨 둔 것 (리뷰가 "두어도 된다" 고 본 것)

- `sm2`·`sm3`·`sm-filter-1` 마지막 입력에 `counter: true` 가 없다 — CLAUDE.md 규칙 위반 가능, 이 브랜치 범위 밖. "새로 온 자료" 표시가 미션마다 다르게 보인다.
- `teacher.js` 가 UI 층에서 `localStorage('cutcheck.generated')` 를 직접 읽음 — 기존 선례(`sentence.js`)를 따랐지만 CLAUDE.md "localStorage 는 data 층만" 과 어긋남. `layer.test` 는 core 만 본다.
- 자료별 마지막 결과 계산이 `sentence.js lastResults` 와 `teacher.js` 두 벌.
- 05 정리의 실행 결과는 설계 버전으로 거르지 않아, 설계를 고친 뒤 자료 하나만 다시 돌리면 옛 설계 결과가 섞여 보일 수 있다.
- 결과 표 E2E 가 에러 칸 색·escape·한 자료 실행 뒤 표 숨김은 확인하지 않음(코드로는 `esc()` 확인).
- 작은 것: `.define-card.selected` 1px 흔들림, `state.judges`/`state.runs` 죽은 상태, `#req-from` 죽은 줄, 어두운 `@media` 들여쓰기, `.lg-gray` 색 하드코딩, 말 걸 순간 시각이 감지 시각(서버 폴링 최대 5초 늦음), `aria-label` 만 있는 div(역할 없음), 새 순간 점이 스크린리더에 안 읽힘.
- `styles.css` 의 `--violet`·`--sun` 은 토큰 표에 없어 그대로 — index·abstract·review 에 보라가 남는다(범위 밖 화면).

## 사람이 판단할 것

1. 강사 "더 보기" 안 **"지금 칭찬해주세요"** 패널 제목을 바꿀지 (CLAUDE.md 는 칭찬 *문구* 를 금지하고, 이 패널은 타이밍만 알린다).
2. 로컬 모드에서 미션 화면 위 **미션 파일 줄** 을 디자인처럼 없앨지 — 없애면 로컬 모드에 미션을 바꾸는 다른 길(예: 위치 표시 "내 미션" 을 눌러 파일 목록으로)이 필요하다.
3. **말 걸 순간에 이미 있던 기록** 도 보여야 하는지 (지금은 화면을 연 뒤 생긴 일만).
4. 서랍의 함정·약한 이유 표시를 중립 문장으로 되살릴지.
5. 폰에서 튜터 버튼을 페이지 끝에 두는 것이 괜찮은지.
6. 내장 미션 `counter: true` 정리를 별도 작업으로 할지.
