### 튜터 리플레이 (Task 3) — 풀이 순서가 보인 답
되묻기를 판정하도록 바꾼 뒤(최종 4회차 실행) 아래만 남았다. 3회차(판정 전 되묻기)에 있던 "아니 모르개서요"·"ㅇㄴ 그니까 그거를…"·"ㄱㄴㄲ"·"split은 뭐고" 첫 응답의 풀이 순서 되묻기는, 4회차에서 판정에 걸려 재요청으로 갔다.
재답은 시간 예산 때문에 판정하지 않는다. 그래서 재요청된 되묻기 중에도 쉼표·나누기를 지목하는 것이 남는다 (4회차 원문):
- "ㄱㄴㄲ 그 문법이 뭐냐고" → `지금 출력이 한 줄 통째로 나오는데, 쉼표 기준으로 나뉜 각 메뉴를 따로 보려면 어떤 모양으로 바꿔야 할까요?`
- "그 문법을 사용하는 방법" → `지금 문자열에서 각 메뉴를 따로 보려면 글자를 어떤 기준으로 나눠야 하나요?`
- "split은 뭐고" → `쉼표로 나눈 뒤 같은 메뉴를 셀 때, 각 메뉴를 담을 칸은 하나만 만들면 되나요?`
- "아니 우째야되냐고요" → `지금은 문자열 한 덩어리만 출력해요. 쉼표 기준으로 나눠서 세려면 어떤 값을 먼저 따로 꺼낼까요?`
- "그러면 딕셔너리를 이용해서 … 예시를 보여줘" → `입력을 쉼표로 나눈 뒤, 없는 메뉴면 1로 넣고 있는 메뉴면 1을 더하는 방식으로 직접 바꿔 볼 수 있나요?`
판정을 통과한 answer 중 풀이 순서가 보이는 것 (4회차):
- "ㅇㄴ 답이 아니라 ㅠ저 코드를 쓰는 문법과 방법을 알려주세욤" → `딕셔너리는 `이름[키] = 값`으로 넣고, 같은 키가 이미 있으면 값을 바꾸는 식이에요. 예를 들어 `count['김밥'] = 1`처럼요. 메뉴를 세려면 먼저 메뉴를 하나씩 꺼내서, 있으면 `+1`, 없으면 1로 넣는지 확인해야 해요. `dict.get(키, 기본값)`도 자주 써요. 한 줄 예시: `count['김밥'] = count.get('김밥', 0) + 1``
