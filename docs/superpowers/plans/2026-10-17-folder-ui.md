# 폴더 UI 적용 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 승인된 디자인 초안(교실=폴더, 미션=파일)을 학생 화면(`sentence.html`)과 강사 화면(`teacher.html`)에 적용한다. 동작은 그대로, 모양과 화면 구조만 바꾼다.

**Architecture:** 색·글꼴은 기존 토큰 이름의 값만 바꿔 한 곳에서 전체에 퍼지게 한다. 폴더·파일·단계 탭 같은 공통 모양은 `sentence.css` 끝에 클래스로 한 벌 둔다(`teacher.html` 도 `sentence.css` 를 읽는다). 화면 구조는 기존 id 를 유지한 채 감싸는 마크업과 렌더 함수만 바꾼다.

**Tech Stack:** 정적 HTML + ES5, CSS 변수, Playwright E2E, node 테스트.

**Spec:** `docs/superpowers/specs/2026-10-17-folder-ui-design.md` · 디자인 원본: `docs/design/2026-10-17-folder-ui/*.dc.html` (각 파일의 `<x-dc>` 안 마크업과 `<helmet><style>` 이 화면의 기준이다. `support.js` 는 없어 파일만 열면 안 그려진다 — 마크업을 읽고 옮긴다. `{{…}}`·`<sc-for>` 는 디자인 도구 문법이니 JS 렌더로 바꾼다.)
