## 1. 경계값 반례 (사람: "경계값 넣자")

- 반례 축이 넷에서 다섯: 개수 변화 / 구분자 변화 / 빈 결과 / 보이지 않는 차이(앞뒤 공백) / **경계값**(기준과 정확히 같은 값 — `>` vs `>=`, 첫·마지막 원소, 0, 길이 1).
- CLAUDE.md "새 미션을 추가할 때" 3번, 미션 생성 프롬프트·검사(`api/`), 생성 미션 검사 테스트에 반영. 기존 미션 데이터는 바꾸지 않는다(축 이름만 추가).

## 2. 문법 제공 (사람: "문제를 푸는 데 필요한 해결 방법이 문법일 경우 제공")

- 학생이 물은 것을 풀려면 특정 문법(예: `dict.get`, `split`, `range`, 리스트 인덱스)이 필요하면 튜터는 **그 문법을 알려 준다**: 이름 · 생김새 · 미션과 상관없는 짧은 예시 1~2줄.
- 여전히 막는 것: 학생의 미션 자료·변수에 바로 적용한 코드, 풀이 순서, 하드코딩 유도.
- 판정(judge)도 같은 기준: 일반 예시는 통과, 미션 자료에 붙인 것은 leak.
- 확인: 평가 스크립트(`test/eval_tutor.py`)로 문법 질문 묶음을 실제 LLM 에 돌려 고정 되묻기·거절 비율을 적는다(운영 기록의 "코드는 직접 써 보는 거예요" 반복 사례 포함).

## 3. 레벨 테스트 상·중·하 (사람이 정함)

- 문제지 셋을 미리 만든다: **하 · 중 · 상** 각 10문항(객관식+단답형 섞음), `js/core/onboard.js` 에. 지금 문제지는 "중"으로 쓴다. 정답표는 그 파일 밖으로 나가지 않는다(지금 규칙).
- 강사가 학생에게 레벨 테스트를 **지정할 때 문제지(하/중/상)를 고른다**. 지정 안 된 신규 학생의 첫 입장 테스트는 "중".
- **기록이 남는다**: 언제 · 어느 문제지 · 문항별 학생 답. 점수는 저장하지 않고 강사 화면이 정답표로 계산해 보여 준다(이벤트 `NEVER` 규칙 유지 — 필드 이름에 `score`·`level` 금지, 문제지는 `set: 'low'|'mid'|'high'`).
- 강사 화면 학생 상세에 **레벨 테스트 기록** 목록: 날짜 · 문제지 · 맞힌 수/10 · 문항별 ○/× · 계산된 레벨.
- **재테스트 알림**: 마지막 레벨 테스트 뒤 **2개월(60일)** 이 지나면 알림(이름표 "레벨 테스트") `OO의 레벨 테스트가 두 달 지났어요. 다시 지정할까요?` — 학생당 한 번, 지정하면 사라짐.
- 학생은 문제지 난이도도 점수도 **절대 못 본다**(문제 화면에 하/중/상 표시 없음, 끝 화면에 결과 없음).
- 저장: `enrollments` 에 지정 문제지 열(`onboard_set`) 추가 — 마이그레이션.

## 4. 철학과 실제가 다른 것 (사람: "알아서 고치고")

먼저 지금 코드에서 아직 그런지 확인하고, 그런 것만 고친다.
1. `s-redefine` 가 `from == to` 로 기록돼 처음 고른 성공 조건이 사라짐(`js/ui/sentence.js` ~318) → 실제 이전 값을 기록.
2. 기본 미션 마지막 입력에 `counter: true` 누락(sm2 · sm3 · sm-filter-1 등) → 규칙대로.
3. 이유 칸을 비우거나 "." 만 써도 넘어감 → 글자(한글·영문·숫자) 2자 이상이어야 다음. 문구는 위치와 사실만(`이유를 한 줄 적어 주세요.`).
4. `s-define` 에 함정 여부(`trap`)가 기록되지 않아 강사 화면 위험/다음 질문이 죽어 있음 → 기록하고 그 화면 기능이 살아나는지 확인.
5. 3단계 제목 "어떻게 할까?" 반말 → 화면 문구 규칙대로(존댓말 또는 학생 1인칭 명사형).
6. 에러 도움 창(`#help-dialog`)을 여는 버튼이 없음 → 있으면 열 수 있게, 쓸모가 없으면 지운다.
7. 튜터 답 안의 백틱 코드를 코드 모양으로(텍스트로만 — innerHTML 금지).
8. 오프라인 저장소 200개 상한 — 상한에 닿을 때 서버에 올라간 것만 지우는지 확인, 안 올라간 기록이 지워지면 고친다.
9. `docs/수업-흐름/t6-credentials.png` 에 실제 학생 계정 정보 → 가짜 데이터로 다시 찍은 그림으로 바꾼다.
10. `docs/수업-흐름.md` 의 "생성 미션 수정 가능" 서술과 실제 화면이 다르면 문서를 실제에 맞춘다.
