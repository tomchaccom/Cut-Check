# 화면 개편 — 접는 사이드바 · 알림 패널 · 학생 튜터 사이드바

2026-10-20 · 사람이 시안으로 정함. 시안: Claude 아티팩트 "선생님 화면 개편 시안"
(https://claude.ai/artifact/WMtmSpsuhPpqfk4oeSKiiu, 원본 파일은 세션 scratchpad `design-canvas/project/*.dc.html`).
이 문서는 시안이 말하지 않는 규칙과 사람이 대화로 정한 것을 적는다.

## 왜

- 지금 선생님 화면은 가운데 한 줄에 다 몰려 있고, 학생 상세는 서랍이라 좁다. 시선이 퍼진다.
- 선생님은 튜터와 대화하지 않는다. 오른쪽은 "지금 누구를 봐야 하나"(알림)가 차지해야 한다. 튜터는 학생 화면에만.
- 칭찬은 사람이 한다(CLAUDE.md). 그래서 기계는 **칭찬 타이밍**만 알린다 — 말은 선생님이.

## 사람이 정한 것

1. 미션 만들기는 탭 둘: **단계별로 만들기 / 한 번에 만들기**. 단계별은 4단계(수업 내용 → 개념 확인 → 이야기 고르기 → 문제 확인), 끝난 단계는 요약 + "고치기", 남은 생성 수와 언제 차감되는지(3단계 "문제 만들기"에서만 1개) 표시.
2. 왼쪽 사이드바는 접힌다(264px ↔ 72px 아이콘 줄). 교실 목록, 고른 교실의 학생 / 미션 / 학생 추가, 아래에 관리자 · 설계 의도 · 로그아웃.
3. 오른쪽 사이드바는 접힌다. **선생님 = 알림**, **학생 = 튜터**. 일반 데이터·자료는 오른쪽에 두지 않는다.
4. 본문은 한 열(최대 760px, 나침반 카드·표처럼 넓어야 하는 것만 본문 폭 전체).
5. 학생 상세는 서랍이 아니라 본문 화면(시간순 기록 + 나침반 + 그 학생의 튜터 대화·짚을 거리).
6. 관리자 · 새 교실 화면에는 오른쪽 패널 없음.
7. 휴대폰: ☰ + 탭 + 아래 노란 막대(선생님 = 알림, 학생 = 튜터).
8. WCAG 2.2 AA: 본문 17px, 버튼 44~52px, 대비 4.5:1, 포커스 테두리.
9. 이름 KOMPAS, 로고 = `favicon.svg` (이미 배포됨).

## 알림 (선생님 오른쪽 패널)

종류 셋, 화면에 이름표로 보인다. 위에 "전체 / 칭찬 타이밍 / 살펴볼 것" 고르기.

| 이름표 | 언제 (학생·미션당 종류별 한 번) | 문장 (사실만) | 누르면 |
|---|---|---|---|
| 칭찬 타이밍 | 첫 `s-code-judge` | `OO이 미션 이름을 마쳤어요. 나침반을 보고 한마디 적어 주세요.` (로컬 모드는 나침반 문장 없이) | 학생 상세 — 나침반 카드 |
| 칭찬 타이밍 | `s-redefine` (성공 조건을 스스로 다시 정함) | `OO이 성공 조건을 스스로 바꿨어요.` | 학생 상세 |
| 칭찬 타이밍 | 에러 난 `s-code` 뒤 다른 코드로 에러 없는 `s-code` | `OO이 에러가 난 뒤 스스로 고쳐 다시 돌렸어요.` | 학생 상세 |
| 살펴볼 것 | `CC.facts` 의 hardcode 사실이 처음 생김 | `OO — 새로 온 자료에서도 첫 자료와 결과가 같아요. 하드코딩일 수 있어요.` | 학생 상세 |
| 살펴볼 것 | 한 미션의 `s-tutor` 가 5번째가 될 때 (기준 `TUTOR_MANY = 5`, 상수 하나) | `OO이 미션 이름에서 튜터에게 5번 물었어요.` | 학생 상세 — 튜터 대화 |
| 살펴볼 것 | 학생이 설계도를 냄 (`sDesignCount` 증가) | `OO이 설계도를 냈어요.` | 학생 상세 |
| 레벨 테스트 | 건너뛰지 않은 `s-onboard` | `OO이 레벨 테스트를 마쳤어요. 레벨 중.` (레벨은 선생님 화면이라 보여도 됨) | 학생 상세 |

- 지금 규칙 유지: 화면을 처음 열 때 이미 있던 것은 알리지 않는다(새로고침마다 쏟아지면 알림을 끈다). 순서 번호·소요 시간·순위·반 평균 없음. 칭찬 문장 없음.
- 알림은 이 브라우저에서 읽음 표시(굵게 → 보통)만 한다. 서버에 저장하지 않는다.
- 판단 규칙은 `js/core/alerts.js` 한 곳(순수 함수). 화면은 그리기만.
- 지금의 "말 걸 순간" 목록은 이 패널로 옮기고 본문에서는 없앤다. 학생 카드의 노란 표시(새 순간)와 "한마디 기다림" 꼬리표는 유지.

## 학생 화면

- 미션 화면 오른쪽에 접히는 튜터 사이드바. 지금 대화창(미션별 세션, 지난 대화, Enter 전송, "답을 쓰는 중이에요")의 동작은 그대로, 자리만 옮긴다. 휴대폰은 아래 노란 막대 → 누르면 전체 화면 대화.
- 레벨 테스트 · 내 나침반은 지금 동작 그대로(시안 모양으로 다듬기만).

## 하지 않는 것

- 서버·DB 변경 없음(알림은 이미 있는 이벤트로 계산).
- 반 전체 현황을 학생 화면에.
- 알림을 숫자 배지로 세기(“3”) — 대신 이름표 개수 문장은 휴대폰 막대에만("칭찬 타이밍 3개") 허용. 순위·비교가 아니라 쌓인 할 일의 양이다.
