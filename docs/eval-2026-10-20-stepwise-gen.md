## 사람 대신 고르기

기준(우선순위 순): 1 짧다 · 2 현실적이고 왜 필요한지 보인다 · 3 쉽다 · 4 자료가 요일 이름만 바뀌는 반복은 싫다.

| 개념 | 고른 것 | 기준 | 안 고른 것과 이유 |
|---|---|---|---|
| 문자열 나누기 | 친구목록 · 택배주소 | 3·1 / 2 | 버스번호 — 앞·뒷자리를 왜 나누는지 안 보임 |
| 리스트·인덱스 | 시간표 · 책꽂이 | 2·3 / 1·3 | 급식메뉴 — why 줄이 "첫 항목"이라 상황(세 번째)과 어긋남 |
| if | 합격 점수 · 버스 탑승 | 2 / 2 | 우산·도서관 입장 — 숫자 기준이 없어 if 가 비교 없이 끝남 |
| for | 우유 팩 · 책갈피 수 | 2·3 / 1·3 | 첫 묶음 5개(급식 줄세기·스티커 개수…)가 전부 `len()` 으로 풀리는 "몇 개 세기" → **"다른 예시 더 보기" 1번** |
| while | 용돈 모으기 · 게임 체력 | 2·3 / 3 | 스쿨버스 기다리기 — 자료가 무엇일지 안 보임 |
| 딕셔너리 | 반장투표 · 급식메뉴 | 2 / 3·1 | 교실열쇠 — 왜 필요한지 약함 |
| 집합 | 같은 시간 · 공통 준비물 | 2 / 2·3 | 급식 선호 — "겹치지 않게 나눠요"가 모호 |
| 함수 | 택배무게 · 시험점수 | 2·1 / 3 | 냉방온도 — 규칙이 상황에 없음 |

"이렇게 바꿔 줬으면"은 두 번 썼다: 버스 탑승("잔액이 요금보다 적은지 숫자로 비교하게"), 우유 팩("자료 이름은 요일 말고 친구마다" — 기준 4).
둘 다 반영됐다.

**예시 목록 자체에 대한 평**: 길이는 모두 세 줄 안이고 존댓말·45자 규칙을 지켰다(서버 검사로 걸러진 것 0개).
하지만 for 첫 묶음 5개가 모두 "몇 개 세기"였고(사람이 싫다고 한 꼴에 가깝다), index 의 why 줄이 상황과 어긋난 것이 하나 있었다.
split 은 3개만 나왔다(서버가 3개 이상이면 재요청하지 않음).

## 돌린 횟수

1. `--dry` 가짜 LLM 한 바퀴(흐름·저장·검사 호출 확인).
2. `examples` 1번(8개념) + `--more` 1번(for·split).
3. `build` 1회차 16개 → 걸린 점이 구조적이라 `_steps.py` 를 고쳤다(아래 "이번에 고친 것").
4. `build` 2회차 16개 전부 다시(따로 풀기 수정이 모든 개념에 걸려서, 예산이 충분해 두 개념만이 아니라 전부). 이 문서의 미션 전문은 2회차다.

## 개념별 한 줄

| 개념 | 한 줄 |
|---|---|
| 문자열 나누기 | 쓸 만하다. 반례(조각 수 변화)가 진짜로 기준을 깬다. 요청이 "쉼표로"를 말해 버리는 버릇이 있다. |
| 리스트·인덱스 | 책꽂이는 좋고 시간표는 반례가 억지. "짧은 반례 = 에러, 긴 반례 = 반례 아님" 긴장이 있어 3번 만들었다. |
| if | 돌지만 쉽다 못해 비어 있다 — 요청이 규칙을 다 말해 학생 판단이 비교 하나뿐. 출력 낱말이 정해지지 않아 따로 푼 답이 갈림. |
| for | 사람이 좋아하는 "모두 더하기" 꼴로 나온다. 다만 `sum()` 이면 for 없이 풀린다. |
| while | 가장 자연스럽다. "닿을 때까지"·"쓰러질 때까지"가 while 그대로. 게임 체력은 값 셋이라 쉬움 수준엔 무겁다. |
| 딕셔너리 | 반장투표는 이번 16개 중 가장 좋다. 대신 고친 프롬프트가 찾기형 소재(메뉴 → 가격)를 세기형으로 밀었다. |
| 집합 | 고친 뒤 둘 다 안정. "둘 다 되는 시간"은 사람 기준 딱 맞지만 자료 꼴이 중1에겐 무겁다. |
| 함수 | 가장 약하다. 둘 다 함수 없이 풀리고, 함수는 한두 줄을 감쌀 뿐. 함수가 꼭 필요한 소재를 못 만든다. |

## 고칠 거리 (이번에 안 고친 것)

1. **출력 꼴이 요청에 없다** — 따로 풀기가 갈린 3개 전부(없음/빈 줄, 탈수있음/탈 수 있어요). 학생도 같은 데서 갈린다. 요청에 "없으면 없음", "가능/불가" 같은 출력 낱말을 쓰게 하는 규칙. (방법이 아니라 결과라 브리프 규칙과 안 부딪친다.)
2. **개념 없이도 풀리는 문제** — for(`sum`), while(나눗셈), 집합(리스트), 함수(전부). 검사는 모범 답안이 개념을 쓰는지만 본다. 스펙의 "고른 개념 없이도 풀리는 문제" 실패를 아직 못 막는다. 따로 풀기 결과 코드에 개념이 없으면 강사에게 사실 한 줄로 보이는 정도가 다음 단계.
3. **반례 축 표시가 틀린다** — if 의 결과 반전을 count/empty 로 표시. 축이 두 개뿐이라 if·함수 소재에 맞는 축이 없다(경계값 축은 사람 결정 대기, 스펙 "사람에게 물을 것" 1).
4. **반례가 기준을 안 깨는 경우** — 시간표 2회차, 우유 팩, 택배무게: 반례 답이 자료 1과 다르기만 하면 통과한다.
5. **동점·숨은 규칙** — 반장투표 반례가 동점, 시험점수 반례 D 는 표에 없는 규칙. 따로 풀기가 우연히 맞춰 신호가 안 떴다.
6. **dict `NEED` 가 찾기형 소재를 세기형으로 민다** — "자료는 리스트로"가 너무 세다. 찾기형이면 "가격표는 모범 답안 안에 딕셔너리로, 자료는 주문 목록" 같은 꼴을 예로 들어야 한다.
7. **상황이 매번 "~해서 곤란해요" + "~를 알아야 해요"** — 프롬프트의 두 문장 틀을 그대로 따라 16개가 다 같은 리듬이고 60~80자로 길다(기준 1).
8. 요청에 `data에 들어 있는` 이 두 번 나왔다 — 변수 이름은 학생 문장에 안 나오는 게 낫다(검사 대상 낱말에 추가 고려).
9. 서버 안 재요청의 최다 사유가 `print 는 딱 한 번`(4번) — 프롬프트 맨 끝 규칙이 잘 안 지켜진다. 비용은 작다.

## 3차 — 리뷰 반영 (개념 없이 풀림 · dict 꼴 · 출력 낱말)

리뷰에서 받은 세 가지와, 그걸 돌리다 새로 나온 한 가지를 고치고 **영향받는 12개만** 다시 만들었다
(문자열 나누기 1 · if 1 · for 2 · while 2 · 딕셔너리 2 · 집합 2 · 함수 2. 택배주소·시간표·책꽂이·합격 점수는 그대로).

### 바꾼 것

| 무엇 | 어디 | 왜 |
|---|---|---|
| **따로 푼 풀이에 고른 개념이 없으면 사실 한 줄** — "따로 푼 답과 같아요 · 따로 푼 풀이에는 고른 개념(반복문 for)이 쓰이지 않았어요" | `js/ui/genflow.js` `solve()` (+ e2e 1개, 기존 두 e2e 는 for 를 쓰는 풀이로) | 스펙의 "고른 개념 없이도 풀리는 문제"가 계속 나오는데 강사에게 아무것도 안 보였다. 판정·탈락이 아니라 강사만 보는 사실. 조사는 개념 이름(`for`·`while` 처럼 영어로 끝남)에 붙이면 읽는 소리가 갈려 "개념(…)이"로 붙였다 |
| `sum()·len()·max() 한 번으로 풀리면 그 개념 없이 풀리는 문제다` | `BUILD_SYSTEM` | 같은 이유 — 만들 때부터 피하게 |

### 고칠 거리 갱신

- 1(출력 낱말) — **고침**. 3차 불일치 1개는 출력 낱말이 아니라 숨은 규칙.

- **걸리는 점**: 반례 "소풍 간 1반"의 걷기·도시락은 교시 과목이 아니라 억지. 반례가 아무 기준도 깨지 않는다(4개 이상이면 그냥 돈다). 요청에 "data에 들어 있는"이 나온다. 3번 만들어서야 통과 — 반례를 짧게 만들면 에러, 길게 만들면 반례가 아님(인덱스 개념의 구조적 긴장).

#### index-2. 책꽂이 → 「책꽂이 확인」

- **고른 예시**: 책꽂이 — 책이 꽂힌 순서가 있어요. 맨 뒤 책이 무엇인지 알아내요. (→ 마지막 칸을 바로 찾기)
- **고른 이유**: 1 짧다 + 3 쉽다 — '맨 뒤 책' 한 가지만 묻는다. 반례(책 수가 바뀜)가 자연스럽다
- **상황**: 지우는 도서관 정리를 하다가 찾는 책이 맨 끝칸에 있어야 하는데 제목을 몰라 곤란해요. 어느 책 제목을 가져가야 하는지 알아야 해요.
- **요청**: 책꽂이의 맨 끝칸에 있는 책 제목을 구해 주세요.
- **자료 · 정답(모범 답안 실행값)**:

  | 자료 | data | 정답 |
  |---|---|---|
  | 민지네 교실 책꽂이 | `['과학','국어','미술']` | 미술 |
  | 준호네 문고 | `['수학','사회','영어']` | 영어 |
  | 도서관 복도 책꽂이 (반례 · count) | `['안전수칙']` | 안전수칙 |

- **카드**: 맨 끝칸 정하기 · 그 칸 값 꺼내기 · 제목 출력하기 · 첫 칸과 비교 *(헷갈리는 카드)*
- **성공 보기**: 진짜 「맨 끝칸 책 제목이 나오면 성공」 · 운 함정 「에러 없이 끝나기만 하면 성공」 · 외우기 함정 「민지네 교실 책꽂이의 답과 같은 미술이 나오면 성공」
- **모범 답안**:

```python
print(data[-1])
```
- **기계 검사**: 통과 — 만들기 1번. 1회차: 통과 (1번)
- **따로 풀기**: 같음 — 미술 / 영어 / 안전수칙
- **좋은 점**: 짧고 쉽다. 책 한 권짜리 반례가 data[2] 같은 외운 자리를 깨뜨린다.
- **걸리는 점**: "찾는 책이 맨 끝칸에 있어야 하는데 제목을 몰라" — 왜 필요한지가 억지스럽다.


### 조건문 if (`if`)

#### if-1. 합격 점수 → 「합격 표시」

- **고른 예시**: 합격 점수 — 수학 점수가 60점 이상이면 통과로 표시해요. (→ 기준 넘으면 통과)
- **고른 이유**: 2 현실적 — 수행평가 60점 기준은 사람이 고른 예시와 같다. 우산·도서관 입장은 숫자 기준이 없어 뺐다
- **상황**: 민준이가 학급 게시판에 올릴 결과를 빨리 정리해야 해서 곤란해요. 수학 점수가 60점 이상인지 보고 무엇을 적을지 알아야 해요.
- **요청**: 수학 점수가 60점 이상이면 통과, 아니면 재도전을 출력해 주세요.
- **자료 · 정답(모범 답안 실행값)**:

  | 자료 | data | 정답 |
  |---|---|---|
  | 소연 | `{'이름':'소연','수학':83}` | 통과 |
  | 준호 | `{'이름':'준호','수학':60}` | 통과 |
  | 하린 (반례 · count) | `{'이름':'하린','수학':45}` | 재도전 |

- **카드**: 수학 점수 보기 · 60 이상 판단 · 결과 정하기 · 결과 출력 · 이름 길이 세기 *(헷갈리는 카드)*
- **성공 보기**: 진짜 「통과 또는 재도전이 나오면 성공」 · 운 함정 「에러 없이 끝나기만 하면 성공」 · 외우기 함정 「소연의 답과 같은 통과가 나오면 성공」
- **모범 답안**:

```python
if data['수학'] >= 60:
    result = '통과'
else:
    result = '재도전'
print(result)
```
- **기계 검사**: 통과 — 만들기 1번. 1회차: 통과 (1번)
- **따로 풀기**: 같음 — 통과 / 통과 / 재도전
- **좋은 점**: 수행평가 60점 기준 그대로. 자료 2가 정확히 60(이상/초과 차이)이라 수업 핵심을 건드린다.
- **걸리는 점**: 요청이 규칙을 다 말해 준다("60점 이상이면 통과, 아니면 재도전") — 학생이 판단할 게 비교 하나뿐. 반례 축 표시가 count 인데 실제로는 결과 반전이다.

#### if-2. 버스 탑승 → 「버스 탑승」

- **고른 예시**: 버스 탑승 — 카드 잔액이 있으면 버스에 탈 수 있어요. (→ 잔액 있나 확인하기)
- **고른 이유**: 2 현실적 — 교통카드 잔액은 중학생이 매일 겪는다
- **이렇게 바꿔 줬으면**: 잔액이 버스 요금보다 적은지 숫자로 비교하게 해 주세요.
- **상황**: 민지가 버스를 타려는데 카드에 돈이 남았는지 몰라 곤란해요. 탈 수 있는지 알아야 해요.
- **요청**: 카드로 버스를 탈 수 있는지 알려 주세요.
- **자료 · 정답(모범 답안 실행값)**:

  | 자료 | data | 정답 |
  |---|---|---|
  | 민지 | `{'잔액': 1500, '요금': 1200}` | 탈수있음 |
  | 준호 | `{'잔액': 1300, '요금': 1200}` | 탈수있음 |
  | 서연 (반례 · empty) | `{'잔액': 900, '요금': 1200}` | 못탐 |

- **카드**: 잔액 보기 · 요금 보기 · 탈 수 있는지 정하기 · 결과 말하기 · 잔돈 계산 *(헷갈리는 카드)*
- **성공 보기**: 진짜 「탈수있음 또는 못탐이 나오면 성공」 · 운 함정 「에러 없이 끝나기만 하면 성공」 · 외우기 함정 「민지의 답과 같은 탈수있음이 나오면 성공」
- **모범 답안**:

```python
if data['잔액'] >= data['요금']:
    answer = '탈수있음'
else:
    answer = '못탐'
print(answer)
```
- **기계 검사**: 통과 — 만들기 1번. 1회차: 불통과 (3번, 반례의 결과가 첫 자료의 결과와 같아요.)
- **따로 풀기**: 다름 — 탈 수 있어요 / 탈 수 있어요 / 탈 수 없어요
- **좋은 점**: 교통카드 잔액은 중학생이 매일 겪는다. 짧다.
- **걸리는 점**: 무엇을 출력할지("탈수있음"/"못탐")가 요청에 없어 따로 푼 답이 "탈 수 있어요"로 갈렸다 — 학생도 같은 데서 갈린다. 반례 축 표시가 empty 인데 실제로는 결과 반전.


### 반복문 for (`for`)

#### for-1. 우유 팩 → 「우유 팩 합계」

- **고른 예시**: 우유 팩 — 오늘 마신 우유 팩 수가 하루마다 적혀 있어요. 며칠 동안 몇 팩인지 더해요. (→ 여러 값을 차례로 더하기)
- **고른 이유**: 2 현실적 + 3 쉽다 — 매점 영수증처럼 '모두 더하기'. 첫 묶음 5개는 모두 len() 으로 풀리는 '몇 개 세기'라 '다른 예시 더 보기'를 한 번 눌렀다
- **이렇게 바꿔 줬으면**: 자료 이름은 요일 말고 반 친구마다 다르게 해 주세요.
- **상황**: 민지가 분리수거 봉투를 사야 하는데 집에서 오늘까지 마신 우유 팩이 모두 몇 개인지 몰라 곤란해요. 봉투는 우유 팩 10개마다 1장이라서, 며칠 동안 마신 수를 모두 알아야 해요.
- **요청**: 우유 팩 수를 모두 더한 값을 구해 주세요.
- **자료 · 정답(모범 답안 실행값)**:

  | 자료 | data | 정답 |
  |---|---|---|
  | 민지네 | `[2, 1, 3, 2]` | 8 |
  | 도윤이네 | `[1, 2, 2, 1, 3]` | 9 |
  | 서연이네 (반례 · count) | `[4, 1]` | 5 |

- **카드**: 합계 시작값 · 하나씩 더하기 · 모두 지나가기 · 결과 출력 · 가장 큰 수 찾기 *(헷갈리는 카드)*
- **성공 보기**: 진짜 「각 자료에서 우유 팩의 전체 개수가 나오면 성공」 · 운 함정 「에러 없이 끝나기만 하면 성공」 · 외우기 함정 「민지네의 답과 같은 8이 나오면 성공」
- **모범 답안**:

```python
total = 0
for milk in data:
    total += milk
print(total)
```
- **기계 검사**: 통과 — 만들기 1번. 1회차: 통과 (1번)
- **따로 풀기**: 같음 — 8 / 9 / 5
- **좋은 점**: 매점 영수증과 같은 "모두 더하기", 현실적(분리수거 봉투). 자료 이름이 요일이 아니라 집마다 다르다(바람 반영).
- **걸리는 점**: 봉투 10개마다 1장은 쓰이지 않는 정보. 반례 [4, 1] 이 아무 기준도 깨지 않는다. sum(data) 로 for 없이 풀린다 — 검사는 모범 답안만 본다.

#### for-2. 책갈피 수 → 「책갈피 장수」

- **고른 예시**: 책갈피 수 — 친구에게 나눠 줄 책갈피가 여러 묶음 있어요. 모두 몇 장인지 알아내요. (→ 묶음마다 같은 일을 반복하기)
- **고른 이유**: 1 짧다 + 3 쉽다 — 묶음마다 장수를 더한다. 더하기가 꼭 필요하다
- **상황**: 민지가 축제에서 친구들에게 책갈피를 나눠 주려는데 묶음이 여러 개라서 바로 세기 어려워요. 모두 몇 장인지 알아야 모자라지 않게 챙길 수 있어요.
- **요청**: data에 들어 있는 묶음들을 보고 책갈피를 모두 몇 장인지 구해 주세요.
- **자료 · 정답(모범 답안 실행값)**:

  | 자료 | data | 정답 |
  |---|---|---|
  | 도서관 준비함 | `[5, 3, 4]` | 12 |
  | 교실 뒤 상자 | `[2, 6, 1, 3]` | 12 |
  | 동아리 책상 (반례 · empty) | `[]` | 0 |

- **카드**: 합계 시작값 · 묶음 하나씩 보기 · 장수 더하기 · 결과 출력 · 가장 큰 묶음 *(헷갈리는 카드)*
- **성공 보기**: 진짜 「전체 책갈피 장수가 나오면 성공」 · 운 함정 「에러 없이 끝나기만 하면 성공」 · 외우기 함정 「도서관 준비함의 답과 같은 12가 나오면 성공」
- **모범 답안**:

```python
total = 0
for pack in data:
    total += pack
print(total)
```
- **기계 검사**: 통과 — 만들기 1번. 1회차: 통과 (1번)
- **따로 풀기**: 같음 — 12 / 12 / 0
- **좋은 점**: 짧고 쉽다. 빈 묶음 반례(0)가 자연스럽다.
- **걸리는 점**: 자료 1과 2의 답이 둘 다 12 — 학생이 결과를 비교할 때 헷갈린다. sum(data) 로 for 없이 풀린다. 요청에 "data에 들어 있는"이 나온다.


### 반복문 while (`while`)

#### while-1. 용돈 모으기 → 「용돈 모으기」

- **고른 예시**: 용돈 모으기 — 매주 3000원씩 모아 목표 금액에 도달할 때까지 모아요. (→ 목표에 닿을 때까지 반복하기)
- **고른 이유**: 2·3 — 목표 금액까지 몇 주, 사람이 고른 예시 그대로. 왜 반복하는지 보인다
- **상황**: 지민이는 갖고 싶은 물건이 있는데 지금 돈이 모자라서 곤란해요. 매주 3000원씩 모을 때 몇 주가 더 필요한지 알아야 해요.
- **요청**: 목표 금액까지 몇 주 더 모아야 하는지 구해 주세요.
- **자료 · 정답(모범 답안 실행값)**:

  | 자료 | data | 정답 |
  |---|---|---|
  | 민수의 저금통 | `{'지금': 9000, '목표': 15000}` | 2 |
  | 소연의 봉투 | `{'지금': 12000, '목표': 18000}` | 2 |
  | 하늘의 통장 (반례 · empty) | `{'지금': 15000, '목표': 15000}` | 0 |

- **카드**: 지금 돈 보기 · 목표 금액 보기 · 주 수 늘리기 · 돈 3000원 더하기 · 이름 길이 세기 *(헷갈리는 카드)*
- **성공 보기**: 진짜 「필요한 주 수가 나오면 성공」 · 운 함정 「에러 없이 끝나기만 하면 성공」 · 외우기 함정 「민수의 저금통의 답과 같은 2가 나오면 성공」
- **모범 답안**:

```python
money = data['지금']
target = data['목표']
weeks = 0
while money < target:
    money += 3000
    weeks += 1
print(weeks)
```
- **기계 검사**: 통과 — 만들기 1번. 1회차: 통과 (1번)
- **따로 풀기**: 같음 — 2 / 2 / 0
- **좋은 점**: 사람이 고른 예시 그대로. 1차에서 모범 답안에만 있던 "매주 3000원"이 이번엔 상황에 들어갔다(고친 프롬프트 효과). 이미 목표에 닿은 반례(0주)가 좋다.
- **걸리는 점**: 나눗셈 한 줄로도 풀린다(while 없이). 자료 1·2 답이 둘 다 2.

#### while-2. 게임 체력 → 「게임 생존 턴수」

- **고른 예시**: 게임 체력 — 몬스터에게 맞을 때마다 체력이 줄어요. 0 이하가 될 때까지 계속해요. (→ 끝날 때까지 상태를 계속 확인하기)
- **고른 이유**: 3 쉽다 — 중학생이 바로 아는 소재, 0 이하가 될 때까지가 while 의 뜻 그대로
- **상황**: 민수는 게임에서 자꾸 쓰러져서 얼마나 버티는지 몰라 곤란해요. 체력, 한 번 맞을 때 줄어드는 양, 회복량으로 몇 번째에 끝나는지 알아야 해요.
- **요청**: 쓰러질 때까지 몇 번 맞는지 구해 주세요.
- **자료 · 정답(모범 답안 실행값)**:

  | 자료 | data | 정답 |
  |---|---|---|
  | 민수 훈련장 | `{'체력':20,'피해':6,'회복':1}` | 4 |
  | 지연 동굴 | `{'체력':15,'피해':4,'회복':1}` | 5 |
  | 태호 성문 (반례 · count) | `{'체력':5,'피해':9,'회복':0}` | 1 |

- **카드**: 처음값 정하기 · 한 번 맞기 · 남은 체력 고치기 · 맞은 횟수 늘리기 · 이름 순서 바꾸기 *(헷갈리는 카드)*
- **성공 보기**: 진짜 「각 자료에서 쓰러질 때의 맞은 횟수가 나오면 성공」 · 운 함정 「에러 없이 끝나기만 하면 성공」 · 외우기 함정 「민수 훈련장의 답과 같은 4가 나오면 성공」
- **모범 답안**:

```python
hp = data['체력']
dmg = data['피해']
heal = data['회복']
count = 0
while hp > 0:
    hp = hp - dmg
    count = count + 1
    if hp > 0:
        hp = hp + heal
print(count)
```
- **기계 검사**: 통과 — 만들기 1번. 1회차: 통과 (1번)
- **따로 풀기**: 같음 — 4 / 5 / 1
- **좋은 점**: "쓰러질 때까지"가 while 의 뜻 그대로. 따로 푼 답과 같다.
- **걸리는 점**: 회복량까지 셋을 다뤄 중1 "쉬움"에는 무겁다. 회복이 언제 되는지(살아 있을 때만)가 상황에 없다.


### 딕셔너리 (`dict`)

#### dict-1. 반장투표 → 「반장투표 결과」

- **고른 예시**: 반장투표 — 반장 후보별 표 수가 적혀 있어요. 누가 몇 표인지 바로 알아내요. (→ 이름과 표를 짝지어 저장)
- **고른 이유**: 2 현실적 — '단톡방 투표(메뉴별 표)'와 같은 꼴, 누가 몇 표인지 왜 필요한지 보인다
- **상황**: 지민이는 반장투표 종이를 받아 들고 누구를 뽑아야 할지 몰라 곤란해요. 누가 가장 많은 표를 받았는지 알아야 해요.
- **요청**: 가장 많은 표를 받은 후보 이름을 구해 주세요.
- **자료 · 정답(모범 답안 실행값)**:

  | 자료 | data | 정답 |
  |---|---|---|
  | 1반 교실 | `['민수','지우','민수','하린','민수']` | 민수 |
  | 도서관 모임 | `['서준','서준','유나','유나','서준']` | 서준 |
  | 방과후 교실 (반례 · count) | `['가은','도윤','가은','도윤']` | 가은 |

- **카드**: 이름별 표 모으기 · 처음 본 이름 넣기 · 같은 이름 수 늘리기 · 가장 많은 이름 찾기 · 가나다 정렬하기 *(헷갈리는 카드)*
- **성공 보기**: 진짜 「후보 이름 한 명이 나오면 성공」 · 운 함정 「에러 없이 끝나기만 하면 성공」 · 외우기 함정 「1반 교실의 답과 같은 민수가 나오면 성공」
- **모범 답안**:

```python
votes = {}
for name in data:
    if name not in votes:
        votes[name] = 1
    else:
        votes[name] += 1

winner = ''
max_vote = 0
for name in votes:
    if votes[name] > max_vote:
        max_vote = votes[name]
        winner = name

print(winner)
```
- **기계 검사**: 통과 — 만들기 1번. 1회차: 불통과 (3번, 풀이 코드에 고른 개념이 쓰이지 않았어요.)
- **따로 풀기**: 같음 — 민수 / 서준 / 가은
- **좋은 점**: 가장 좋은 결과. 투표 종이 → 이름별 표 → 최다 — 딕셔너리가 꼭 필요하고 현실적이다. 1차에서 3번 다 실패한 것을 프롬프트 수정으로 한 번에 통과.
- **걸리는 점**: 반례가 2:2 동점이라 "누가 이기는지"가 규칙에 없다(먼저 나온 사람). 우연히 따로 푼 답과 같았다.

- **상황**: 지민이는 급식실에서 메뉴별 준비 수량을 적어야 해서 곤란해요. 오늘 주문표를 보고 각 메뉴가 몇 번 나왔는지 알아야 해요.
- **요청**: 주문표에서 메뉴별 나온 횟수를 보여 주세요.
- **자료 · 정답(모범 답안 실행값)**:

- **카드**: 빈 상자 준비 · 이름별 늘리기 · 처음 나온 것 · 결과 보여주기 · 가장 긴 이름 *(헷갈리는 카드)*
- **성공 보기**: 진짜 「메뉴 이름마다 횟수가 묶인 결과가 나오면 성공」 · 운 함정 「에러 없이 끝나기만 하면 성공」 · 외우기 함정 「도서관 급식표의 답과 같은 {'김밥': 2, '우동': 2, '라면': 1}가 나오면 성공」
- **모범 답안**:

```python
counts = {}
for menu in data:

```
- **기계 검사**: 통과 — 만들기 1번. 1회차: 불통과 (3번, 풀이 코드에 고른 개념이 쓰이지 않았어요.)
- **따로 풀기**: 같음 — {'김밥': 2, '우동': 2, '라면': 1} / {'제육덮밥': 3, '돈가스': 1} / {}

- **걸리는 점**: 고른 예시(메뉴 → 가격 찾기)에서 벗어나 "메뉴가 몇 번 나왔는지"가 됐다 — 사람이 싫다고 한 "간식 이름이 몇 번 나왔는지"와 같은 꼴. 고친 프롬프트("자료는 리스트로")가 찾기형 소재를 세기형으로 밀었다. 출력이 딕셔너리 그대로라 길다.


### 집합 (`set`)

#### set-1. 같은 시간 → 「겹치는 연습 시간」

- **고른 예시**: 같은 시간 — 두 모둠이 할 수 있는 시간을 적었어요. 둘 다 되는 시간을 찾아요. (→ 둘 다 되는 것만 찾기)
- **고른 이유**: 2 — 사람이 직접 좋다고 한 '가능한 시간대를 받아 언제 회의할 수 있는지' 그대로
- **상황**: 민서는 모둠 발표 연습 시간을 잡아야 해서 곤란해요. 두 모둠이 모두 되는 시간을 알아야 해요.
- **요청**: 두 모둠이 모두 되는 시간만 찾아 출력해 주세요.
- **자료 · 정답(모범 답안 실행값)**:

  | 자료 | data | 정답 |
  |---|---|---|
  | 도서관 모둠 | `{'가람':'월3,수2,금1','누리':'화1,수2,금1'}` | 금1,수2 |
  | 과학실 모둠 | `{'다온':'화2,목1','라온':'화2,목1,금2'}` | 목1,화2 |
  | 체육관 모둠 (반례 · empty) | `{'마루':'월1,수1','시온':''}` | 없음 |

- **카드**: 두 사람 시간 꺼내기 · 쉼표로 나누기 · 겹치는 것만 고르기 · 순서대로 출력값 만들기 · 가장 빠른 시간 찾기 *(헷갈리는 카드)*
- **성공 보기**: 진짜 「둘 다 되는 시간들만 쉼표로 이어진 글자나 없음이 나오면 성공」 · 운 함정 「에러 없이 끝나기만 하면 성공」 · 외우기 함정 「도서관 모둠의 답과 같은 금1,수2가 나오면 성공」
- **모범 답안**:

```python
a = list(data.values())[0]
b = list(data.values())[1]
sa = set(a.split(',')) if a else set()
sb = set(b.split(',')) if b else set()
ans = sorted(sa & sb)
print(','.join(ans) if ans else '없음')
```
- **기계 검사**: 통과 — 만들기 1번. 1회차: 통과 (1번)
- **따로 풀기**: 다름 — 금1,수2 / 목1,화2 / (빈 출력)
- **좋은 점**: 사람이 직접 좋다고 한 "둘 다 되는 시간" 그대로. 겹치는 시간이 없는 반례가 좋다. sorted 로 순서가 고정됐다(고친 프롬프트 효과).
- **걸리는 점**: 자료가 이름 → 쉼표 문자열 딕셔너리라 중1에게 무겁다(list(data.values())[0]). "없음"을 출력하라는 말이 요청에 없어 따로 푼 답이 빈 줄로 갈렸다.

- **상황**: 민지는 학급 행사 준비를 맡았는데 친구들이 보낸 준비물 쪽지에 같은 물건이 자꾸 겹쳐서 곤란해요. 한 번만 사면 되는 물건이 무엇인지 알아야 해요.

- **좋은 점**: 짧고 현실적. 1차의 print(set(data))(순서가 실행마다 바뀜)가 개수 출력으로 바뀌었다.

### 함수 (`func`)

#### func-1. 택배무게 → 「택배비 계산」

- **고른 예시**: 택배무게 — 짐 무게를 넣으면 배송비를 바로 계산해요. (→ 같은 계산을 매번 반복하지 않기)
- **고른 이유**: 2 현실적 — 무게 → 배송비, 사람이 괜찮다고 한 '배달비 계산기'와 같은 꼴. 1 상황 한 문장
- **상황**: 민수는 반 친구들 택배를 대신 접수하는데, 무게마다 값이 달라 헷갈려요. 각 상자의 무게를 보고 모두 얼마인지 알아야 해요.
- **요청**: 상자들 배송비의 합계를 구해 주세요.
- **자료 · 정답(모범 답안 실행값)**:

  | 자료 | data | 정답 |
  |---|---|---|
  | 지은의 상자 | `{'요금표': {1: 3000, 3: 4000, 5: 5000}, '무게들': [1, 3, 5]}` | 12000 |
  | 도윤의 상자 | `{'요금표': {1: 3000, 3: 4000, 5: 5000}, '무게들': [1, 1, 3]}` | 10000 |
  | 소라의 상자 (반례 · count) | `{'요금표': {1: 3000, 3: 4000, 5: 5000}, '무게들': [5]}` | 5000 |

- **카드**: 무게값 정하기 · 값 더하기 · 계산 틀 만들기 · 틀 사용하기 · 가장 큰 무게 *(헷갈리는 카드)*
- **성공 보기**: 진짜 「합계 배송비가 나오면 성공」 · 운 함정 「에러 없이 끝나기만 하면 성공」 · 외우기 함정 「지은의 상자의 답과 같은 12000이 나오면 성공」
- **모범 답안**:

```python
def fee(w):
    return data['요금표'][w]

total = 0
for w in data['무게들']:
    total += fee(w)

print(total)
```
- **기계 검사**: 통과 — 만들기 1번. 1회차: 통과 (1번)
- **따로 풀기**: 같음 — 12000 / 10000 / 5000
- **좋은 점**: 1차의 "요금 규칙이 모범 답안에만 있음"(따로 푼 답 5000 vs 4000)이 요금표를 자료에 넣는 것으로 고쳐졌다.
- **걸리는 점**: 요금표가 무게 1·3·5 딱 맞을 때만 값이 있어 비현실적. 함수가 dict 조회 한 줄을 감쌀 뿐이라 함수가 꼭 필요하지 않다. 반례가 기준을 깨지 않는다.

#### func-2. 시험점수 → 「등급 확인」

- **고른 예시**: 시험점수 — 점수를 넣으면 등급을 바로 알려 주는 표를 만들어요. (→ 점수마다 같은 결과를 꺼내기)
- **고른 이유**: 3 쉽다 — 점수 → 등급, '학점 바꾸기'와 같은 꼴
- **상황**: 민지는 시험 점수를 빨리 적어야 해서 곤란해요. 점수에 따라 어떤 등급인지 알아야 해요.
- **요청**: 점수표에 맞는 등급을 출력해 주세요.
- **자료 · 정답(모범 답안 실행값)**:

  | 자료 | data | 정답 |
  |---|---|---|
  | 민지의 수학 | `{'점수': 92, '기준': {'A': 90, 'B': 80, 'C': 70}}` | A |
  | 준호의 영어 | `{'점수': 76, '기준': {'A': 90, 'B': 80, 'C': 70}}` | C |
  | 소라의 과학 (반례 · count) | `{'점수': 65, '기준': {'A': 90, 'B': 80, 'C': 70}}` | D |

- **카드**: 점수 꺼내기 · 기준 정하기 · 등급 정하기 · 결과 말하기 · 점수 합치기 *(헷갈리는 카드)*
- **성공 보기**: 진짜 「알맞은 등급 한 글자가 나오면 성공」 · 운 함정 「에러 없이 끝나기만 하면 성공」 · 외우기 함정 「민지의 수학의 답과 같은 A가 나오면 성공」
- **모범 답안**:

```python
def grade(score, rule):
    if score >= rule['A']:
        return 'A'
    if score >= rule['B']:
        return 'B'
    if score >= rule['C']:
        return 'C'
    return 'D'

print(grade(data['점수'], data['기준']))
```
- **기계 검사**: 통과 — 만들기 1번. 1회차: 통과 (1번)
- **따로 풀기**: 같음 — A / C / D
- **좋은 점**: 점수 → 등급, 기준이 자료에 보인다. 따로 푼 답과 같다.
- **걸리는 점**: 반례 D 는 기준표에 없는 규칙(70 밑은 D)이라 학생이 알 수 없다 — 따로 푼 답은 우연히 맞췄다. 함수 없이 if 만으로 풀린다.
