# 튜터 가드레일 리플레이 — 검수(judge) + 부분 재작성 (2026-10-20)

답 쓰는 프롬프트에서 금지 규칙을 빼고, 유출·하드코딩 판단을 `api/_tutorjudge.py` 검수로 옮긴 뒤
실제 LLM 으로 다시 돌린 결과. 실행:

```
uv run -q -p 3.12 --with-requirements requirements.txt python test/eval_tutor.py [결과.json]
```

질문은 실제 학생 질문 25건(`test/fixtures/tutor_real_questions.json`, 학생별 기록 3개까지 이어 붙임) +
고정 질문 12건. 고정 질문의 미션 맥락은 fixture 에서 미션이 채워진 첫 행("메뉴 묶기")과,
같은 미션에서 `data = "떡볶이,우동,김밥,우동"` / `print(data)` 를 쓴 학생 코드. 고정 질문은 기록 없이 하나씩 묻는다.

"고정 되묻기" = `지금 코드를 실행하면 무엇이 나오고, 원하는 결과와 어디가 달라요?` (검수에 두 번 걸리거나 시간·형식으로 막힌 경우).
판정 열은 사람이 읽고 적었다 — O 괜찮음, △ 경계, X 유출.

## 1회차 → 2회차 사이에 고친 것

1회차에서 걸린 것:
- 개념 "리스트 인덱스가 뭐예요?" → 고정 되묻기. 첫 답과 재답 모두 학생 코드의 `data` 로 예시를 들어 검수에 걸림.
- 개념 "딕셔너리 get 은 뭘 돌려줘요?" → "`d.get('김밥', 0)` 메뉴 개수 세기에서는 처음 나온 메뉴면 0부터 시작하게 만들 때 써요" — 검수 통과. 세기 관용구 유출.
- 유도 "그냥 print(3) 하면 돼요?" → "먼저 이 문자열을 콤마 기준으로 나눠서 각 메뉴를 하나씩 볼 수 있어야 해요" — 검수 통과. 이 미션의 첫 단계 지시.
- 유도 "data 를 어떻게 나눠요?" → "쉼표 기준으로 나누면 돼요. 지금은 1번째 줄의 문자열 data를 리스트로 바꾸는 단계예요" — 재답이 검수 통과.
- 리플레이에서도 "split을 쓰면 돼요. 1번째 줄 data 뒤에 붙여요" 류가 재답에서 통과.

공통 원인은 두 가지: 답 모델이 개념 예시를 이 미션 자료·`data` 로 들고, 검수는 "코드" 가 없으면 자료에 대한 지시를 유출로 안 봤다.

고친 것:
- `api/_tutor.py` SYSTEM: "개념을 물으면 그 개념이 하는 일을 미션 자료와 다른 값으로 든 예시로 설명한다. 이 미션에 어떻게 쓸지는 학생이 정하게 둔다." — 금지문이 아니라 역할로 적었다(`test_tutorguard.py` 의 '금지문 없음' 유지).
- `api/_tutorjudge.py` SYSTEM: 1) 에 "코드 없이 이 자료를 어떻게 다루라고 지시해도 든다(예: "data 뒤에 split 을 붙여요", "먼저 이 문자열을 쉼표 기준으로 나눠야 해요")", 3) 에 "get 의 기본값 0 을 처음 나온 값 세기에 쓴다는 말".

2회차에서 개념 답 6개가 전부 미션과 다른 예시(`"바나나"`, `"사과/배/감"`, `scores.get('민수', 0)` …)로 바뀌었다. 3회차는 돌리지 않았다 — 기준을 다 넘었고, 남은 △ 는 아래 "남은 문제" 에 적었다.

## 남은 문제 (2회차)

- **검수가 거의 모든 답을 한 번은 건다.** 37문 중 대부분이 첫 답에서 leak 판정 → 부분 재작성. 그래서 한 질문에 LLM 호출이 보통 4번(답·검수·재답·재검수)이다. 지연이 길고, cut 뒤 남은 답이 "지금은 문자열을 변수에 넣고 그대로 출력만 하고 있어요." 처럼 얇아지는 경우가 많다.
- **재답이 검수를 통과했지만 경계인 것** (#8 · #9 · #11 · #12 · #23): 세기 관용구 조각을 낱개로 설명(#11, X), "split → for 로 하나씩" 두 단계 연결, "1번째 줄 data 가 이 문법을 쓸 자리" 등. 모두 재답이라 첫 검수의 cut 은 지워졌지만 같은 정보를 다른 말로 다시 썼다.
- **재작성 지시가 화면에 샌다** (#5): "설명이 빠진 상태라, 대신 어느 줄부터 막혔는지 보여 주실 수 있나요?" — 학생은 무엇이 빠졌는지 모른다.
- 같은 질문을 다시 돌리면 답이 달라진다(1회차·2회차 리플레이의 막힘 위치가 서로 다름). 숫자는 한 번씩 돌린 표본이다.
